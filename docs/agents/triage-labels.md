# Etykiety triażu

Skille posługują się pięcioma rolami triażu. Ta tabela mówi, jakie etykiety odpowiadają im w zgłoszeniach tego repo.

| Rola w mattpocock/skills | Etykieta u nas    | Znaczenie                                        |
| ------------------------ | ----------------- | ------------------------------------------------ |
| `needs-triage`           | `needs-triage`    | Właściciel musi ocenić zgłoszenie                |
| `needs-info`             | `needs-info`      | Czekamy na więcej informacji od zgłaszającego    |
| `ready-for-agent`        | `ready-for-agent` | Opisane do końca, gotowe dla agenta bez nadzoru  |
| `ready-for-human`        | `ready-for-human` | Wymaga pracy człowieka                           |
| `wontfix`                | `wontfix`         | Nie będzie robione                               |

Gdy skill mówi o roli (np. „nadaj etykietę gotowe dla agenta”), użyj etykiety z prawej kolumny.
`wontfix` już jest na GitHubie; pozostałe cztery `/triage` założy przy pierwszym użyciu.

Prawą kolumnę można zmienić, jeśli zaczniemy używać innych nazw.
